# Ô, Meu! Troca Esse Disco — Do MER ao MySQL

> *"Na Sé, até disco parado vira desconto."*

Projeto prático individual de banco de dados (MySQL) da disciplina PI II.

## Sobre o projeto
Banco de dados relacional para um sebo fictício de CDs usados na região da Praça da Sé (São Paulo), com catálogo, estoque físico de exemplares e trocas com desconto por estado de conservação.

## Estrutura do repositório
- `docs/` — briefing, regras de negócio, MER, DER, dicionário de dados e evidências
- `database/ddl/` — script de criação da estrutura
- `database/dml/` — scripts de carga e testes de manipulação
- `database/dql/` — consultas
